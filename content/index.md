# Learn

A personal reading space built with **Nuxt Content** in the **Minimalist Monochrome** design language — pure black, white, and typography.

## What's inside

- The [Index](/browse) — searchable list of every page.
- The [Rust curriculum](/rust) — a comprehensive, idiomatic course from zero to pro.

## How it works

Content lives in the `content/` directory as Markdown. The catch-all page at `app/pages/[...slug].vue` queries and renders it with sharp geometry, oversized serif typography, and dramatic negative space.

Explore the [Rust curriculum](/rust) to see technical documentation styled with tables, code blocks, and reading progress.
